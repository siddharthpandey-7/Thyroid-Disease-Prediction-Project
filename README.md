# 🧪 Thyroid Disease Prediction System

An end-to-end machine learning web application that classifies thyroid conditions as **Normal, Hyperthyroid, or Hypothyroid** using five thyroid-related clinical parameters.

The project includes data preprocessing, class balancing, model comparison, evaluation, model persistence, and Flask-based deployment.

---

## 🎯 Features

- Classification of three thyroid conditions:
  - Normal
  - Hyperthyroid
  - Hypothyroid
- Data cleaning and preprocessing
- Feature scaling using `StandardScaler`
- Class balancing using `SMOTE`
- Comparison of five machine learning models
- XGBoost-based prediction
- Prediction probabilities and confidence display
- Rule-based TSH override
- Flask web interface
- Downloadable prediction report
- Custom error handling

---

## 🧪 Input Features

The model uses five clinical parameters:

1. T3 Resin Uptake Test
2. Total Serum Thyroxin (TT4)
3. Total Serum Triiodothyronine (T3)
4. Basal TSH
5. Max TSH Difference

### Prediction Classes

```
1 → Normal
2 → Hyperthyroid
3 → Hypothyroid
```

---

## 🤖 Machine Learning

### Dataset

- 215 samples
- 5 input features
- 3 target classes
- 80/20 stratified train-test split

### Preprocessing

- Missing values (`?`) removed
- Features converted to numeric format
- Target labels encoded
- Features standardized using `StandardScaler`
- SMOTE applied only to the training data

### Models Compared

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- XGBoost

### Evaluation

Models were evaluated using:

- Accuracy
- Weighted F1-score
- Classification report
- Confusion matrix

### Final Model

XGBoost was manually selected as the final model for deployment.

Test-set performance:

- **Accuracy:** 97.67%
- **Weighted F1-score:** 0.9760

> The reported performance is based on a single train-test split of a relatively small dataset and should not be interpreted as clinical or real-world diagnostic accuracy.

---

## 🩺 Rule-Based TSH Override

The Flask application includes a simple rule-based override for extreme Basal TSH values:

```
Basal TSH < 0.4  → Hyperthyroid
Basal TSH > 5.0  → Hypothyroid
```

When the machine learning prediction disagrees with the applicable rule, the rule-based prediction overrides the model prediction.

> These rules are project-specific and are not clinically validated.

---

## 🌐 Web Application

The Flask application:

- Accepts the five input values
- Applies the saved `StandardScaler`
- Generates an XGBoost prediction
- Calculates prediction probabilities
- Applies the TSH override when applicable
- Displays the prediction, confidence, probabilities, and input values
- Allows the prediction report to be downloaded as a `.txt` file
